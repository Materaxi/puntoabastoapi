Módulo de Inventario — Cómo funciona

entrada → Dueño compra mercadería y registra la cantidad en el panel
salida → Se descuenta automáticamente cuando un pedido pasa a estado confirmado
ajuste → Corrección manual (merma, producto en mal estado, conteo físico)
Relación clave: INVENTARIO se vincula a PRODUCTO_UNIDADES (no a PRODUCTOS directamente), porque el stock depende de la unidad.
Ejemplo: Acelga tiene 2 unidades de venta → Amarro (45 disponibles) y Amarro Grande (3 disponibles) — cada una con su propio registro de inventario.

Alerta automática: cuando stock_actual baja de stock_minimo, el campo alerta_activa se activa (vía trigger en PostgreSQL o lógica en la API) y aparece en el panel del dueño.

PEDIDO_ITEMS ahora referencia producto_unidad_id en lugar de producto_id, para que la API sepa exactamente qué unidad descontar del inventario al confirmar el pedido.

Flujo de estados — PEDIDOS.estado

recibido → confirmado ↓ descuenta stock preparando → en_camino → entregado  |  cancelado → revierte stock si estaba confirmado
